*** Windows Installer

Only the 64-bit version is provided. Running the downloaded MSI installer will install the C++ edition, Python edition, Java edition, OpenRTP, rtshell, OpenCV 4.13.0, omniORB 4.3.4, and JRE 8.

*** Linux Packages

For Ubuntu 22.04 and 24.04 (amd64 and arm64 environments), paste the following command into a shell prompt and execute it. The C++ edition, Python edition, Java edition, OpenRTP (amd64 only), rtshell, and JDK 8 will be installed.

 $ bash <(curl -s https://raw.githubusercontent.com/OpenRTM/OpenRTM-aist/master/scripts/openrtm2_install_ubuntu.sh)

For installation instructions, please refer to:

[[Installing OpenRTM-aist 2.1 on Linux:/en/doc/installation/install_2_1/install_linux_2_1]]

*** Raspberry Pi OS Packages

For Bookworm (64-bit environments), paste the following command into a shell prompt and execute it. The C++ edition, Python edition, Java edition, and rtshell will be installed.

 $ bash <(curl -s https://raw.githubusercontent.com/OpenRTM/OpenRTM-aist/master/scripts/openrtm2_install_raspbian.sh)

For installation instructions, please refer to:

[[Installing OpenRTM-aist 2.1 on Raspberry Pi OS:/en/doc/installation/install_2_1/install_raspbian_2_1]]
